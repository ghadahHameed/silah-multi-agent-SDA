# Agent 1 - Product Understanding Agent

This agent receives a product name and description, researches the product and its market context using Tavily, and generates a structured Ideal Customer Profile (ICP).

## Input
- Product name
- Product description

## Output
- Product summary
- Target industries
- Preferred company size

## Scope
Agent 1 does not search for companies, calculate fit scores, rank companies, or generate outreach messages.
